# CRM Chat — Environment Variables Reference

Complete reference for all environment variables used across the project. Copy `.env.example` to `.env` and fill in the required values.

## Convex Backend

| Variable | Required | Default | Used By | Description |
|----------|----------|---------|---------|-------------|
| `CONVEX_SELF_HOSTED_URL` | Yes | `http://127.0.0.1:3210` | Convex CLI | URL of the self-hosted Convex backend |
| `CONVEX_SELF_HOSTED_ADMIN_KEY` | Yes | — | Convex CLI, Dashboard | Admin key generated by `docker compose exec backend ./generate_admin_key.sh` |
| `CONVEX_URL` | Yes | `http://localhost:3210` | crm-worker | Convex backend URL for the Rust worker |
| `PORT` | No | `3210` | docker-compose | Host port for Convex API |
| `SITE_PROXY_PORT` | No | `3211` | docker-compose | Host port for Convex site proxy (file uploads) |
| `DASHBOARD_PORT` | No | `6791` | docker-compose | Host port for Convex dashboard |
| `INSTANCE_NAME` | No | — | backend | Convex instance name |
| `INSTANCE_SECRET` | No | — | backend | Convex instance secret |
| `DOCUMENT_RETENTION_DELAY` | No | `172800` | backend | Document retention delay in seconds (default 48 hours) |

## Frontend (Vite)

All `VITE_` variables are compiled into the frontend bundle at build time. In production Docker containers, they are injected at runtime via `env-config.js`.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `VITE_CONVEX_URL` | Yes | — | Convex backend URL (e.g., `http://localhost:3210`). Set in `.env` — do not duplicate across `.env` and `.env.local`. |
| `VITE_CLERK_PUBLISHABLE_KEY` | Yes | — | Clerk publishable key |
| `VITE_ES_PROXY_URL` | No | `http://localhost:3001` | Elasticsearch proxy URL for semantic search |
| `VITE_SENTRY_DSN` | No | — | Sentry DSN for frontend error tracking |
| `VITE_SENTRY_ENVIRONMENT` | No | — | Sentry environment tag (e.g., `production`, `staging`) |
| `VITE_TEST_USERNAME` | No | — | Test user credentials (Playwright tests only) |
| `VITE_TEST_PASSWORD` | No | — | Test user password (Playwright tests only) |

Frontend environment variables are validated at runtime using `@t3-oss/env-core` and Zod in `bins/crm-chat-web/src/env.ts`.

## Elasticsearch (Optional)

Elasticsearch powers optional semantic search. Set `ES_ENABLED=true` to activate.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `ES_ENABLED` | No | `false` | Enable Elasticsearch integration |
| `ES_URL` | No | `http://localhost:9200` | Elasticsearch cluster URL |
| `ES_INDEX` | No | `crm-chat-msgs` | Index name for messages |
| `ES_PIPELINE` | No | `openrouter-pipeline` | Ingest pipeline name |
| `ES_USERNAME` | No | `elastic` | Elasticsearch username |
| `ES_PASSWORD` | No | — | Elasticsearch password |
| `ELASTIC_PASSWORD` | No | — | Elasticsearch password (cluster setup) |
| `OPENROUTER_API_KEY` | No | — | OpenRouter API key for embeddings |
| `INFERENCE_ID` | No | `openrouter-embeddings` | Elasticsearch inference endpoint ID |
| `PIPELINE_ID` | No | `openrouter-pipeline` | Elasticsearch pipeline ID |
| `INDEX_NAME` | No | `crm-chat-msgs` | Elasticsearch index name |
| `MODEL_ID` | No | `openai/text-embedding-3-small` | Embedding model via OpenRouter |
| `EMBEDDING_DIMS` | No | `1536` | Embedding vector dimensions |
